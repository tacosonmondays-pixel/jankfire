# owner look refs, 2026-11-13 (mechs: cooler, anime-mecha / "gundam" style)

The owner sent these four promo pieces from another mech hero shooter and said:
"I want the mechs to be cooler different style from base game like gundam".
They are **look references only**. Take the level of finish and the design language, never the designs,
names, logos, characters or pilots. Every JANKFIRE mech stays an original design. This branch stays off `main`.

| file | what to take from it |
|---|---|
| `01_bear_mech_yellow.png` | a silly idea (a teddy-bear head) executed as serious hardware: heavy layered armour, rivets, chunky fists, a glowing core, big stencil lettering on the chest |
| `02_dragon_mech_red_black.png` | an aggressive silhouette: sharp layered plates, claws, glowing amber eye slits and seams, a two-tone gloss black + red scheme |
| `03_jet_mech_white_blue.png` | the clean "gundam" read: white main armour, dark frame showing at the joints, red accent stripes, glowing cyan edge lines, wing binders, a sharp visor head |
| `04_bubble_mech_red.png` | a round, cute body that still reads as engineered: big glass canopy, unit number decals (shape language, not text), multi-barrel arm, white trim stripes |

What makes them read as "cool mecha" (coordinator notes):
- heroic proportions: small head, broad chest and shoulders, long legs, big hands/feet
- layered armour plates over a darker inner frame that shows at every joint
- panel lines, seams, vents, thrusters, hydraulic pistons; sharp chamfers on hard edges
- two- or three-tone clean paint (one main colour, one frame colour, one accent) with clear coat
- emissive accent lines and eyes (cyan, amber, green) that glow
- decals: unit numbers, warning chevrons, stencil names (our own, e.g. JANK MOTORS)
- every mech has one instantly readable silhouette idea
